■ 概要
dozou_katanuki（土蔵・型抜き）は、Webの深淵から失われた投稿やメディアを
ローカル環境に高忠実度で動態保存（アーカイブ・サルベージ）するための
Wails-Stash ハイブリッドデスクトップアプリケーションです。

■ 起動方法
1. 本フォルダ直下の「START_DOZOU.bat」をダブルクリックしてください。
2. 必要なディレクトリの生成および環境チェックが自動で行われ、アプリが起動します。

■ 終了方法
・アプリのウィンドウ右上の「×」ボタンで終了してください。
・バックグラウンドプロセスを完全に強制終了したい場合は「STOP_DOZOU.bat」を実行してください。

■ フォルダ・ファイル構成
・dozou_katanuki.exe   : メインアプリケーション実行ファイル
・START_DOZOU.bat      : ダブルクリック一発起動ランチャー
・STOP_DOZOU.bat       : 緊急・完全一括終了スクリプト
・config.json          : システム全体の設定ファイル (Admin Board から編集可能)
・archive.db           : アーカイブデータベース (SQLite3 WALモード)
・archive_schema.sql   : データベース初期化用スキーマ定義
・bin/                 : 内部ツール (Stashapp ヘッドレスバイナリ、FFmpeg 等)
・plugins/             : 各SNS用プラグイン (Twitter 等の Scraper/Skin/Renderer)
・assets/              : 静的アセット (アバターキャッシュ等)
・blobs/               : サルベージされた画像・動画メディアのローカル保存先
・stash/               : Stashapp が管理・参照するメディアストレージプール
・backups/dumps/       : レイヤー2 完全オフライン原本スナップショット (WARC / メタデータ)

■ 特殊機能
1. 手動WARCインポート (Admin Board -> ジョブ -> 手動インポート):
   ArchiveWeb.page 等で手動取得した .warc / .warc.gz を指定すると、
   完全オフラインで自動監査・アカウント特定・メディア抽出・DB登録が行われます。

2. LAN メディア配信 & キャスト (Admin Board -> 設定 -> LAN配信):
   同一 Wi-Fi 内のスマートフォンやタブレットから、表示された QR コードや
   URL にアクセスすることで、アーカイブされた動画や画像をどこでも閲覧できます。

3. CSS スキン & フォント編集 (Admin Board -> スキン & フォント):
   タイムラインのデザインやフォントをリアルタイムプレビューしながら自由にカスタマイズ可能です。

■ 動作要件
・OS: Windows 10 / 11 (64-bit)
・Python 3.10+ (Wayback / CDX サルベージ収集を利用する場合に推奨)
・WebView2 ランタイム (Windows 10/11 には標準搭載)
